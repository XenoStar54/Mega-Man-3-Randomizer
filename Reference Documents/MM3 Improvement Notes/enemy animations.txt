Basic format for all types of enemy/boss animations
2 bytes for frames and speed, followed by animation ID for each individual frame

1st byte: Number of frames in animation (00 always counts)
2nd byte: Speed of animation

example: hedgehog enemy when idle ("not" rolling phase)
04 0C xx xx xx xx xx (5 frames of animation at 0C speed)

I'm only going to list the ROM offsets of those first 2 bytes because it's the only important part you should be dealing with.

You can sort of delete frames by simply lowering the 1st byte, but do "not" attempt raise the number because you cant actually "add" any additional frames to anything without completely moving all the pointers and data elsewhere.

Warning: Some enemies may use code for specific AI's by checking a specific frame during their animation. I'm not going to include these because it's soooo much extra countless hours of work to even check all that stuff. (for example an enemy might check the 3rd frame of a specific animation and run code based on that)
