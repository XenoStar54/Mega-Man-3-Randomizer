Megaman 3 Improvement enemy settings
---------------------
This is in order of enemy number order from MegaFLE level editor

Only compatible with Megaman 3 Improvement english version, due to many enemies having edits throughout the history of this hack. Not original Megaman 3.
---------------------
** very important!!
All existing enemies/bosses load a "starting" X speed from tables at the very start of ROM. However, they use a simple pointer to what speed it wants to pick from the table. Most of these are shared by MANY enemies.

For example, editing the base speed of a metool might be shared by several other enemies. please keep this in mind.

Tip: you can just set every single enemy to it's own individual pointer if you chose, to avoid enemies being shared. Cause only about 10 or so actually exist. I hope this makes sense.

510-59F:
enemy type pointer (use megafle to match the enemy type number to this table starting at 510) for example - "Enemy Type 1B hedgehog" refers to 52B
This is the pointer for these 2 tables below:

610-69F:
X speed low

710-79F:
X speed high
